# João Pedro Photography — Portfolio

A refined, responsive photography portfolio built with plain HTML, CSS and JavaScript.

## Quick start
1. Open `index.html` locally to preview.
2. Replace the Unsplash image URLs in `index.html` with your own photographs.
3. Update your email, Instagram, WhatsApp and prices.
4. Upload the folder to a GitHub repository.
5. Enable GitHub Pages under **Settings → Pages → Deploy from branch → main → / (root)**.

## Customize
- Name / logo: `index.html`
- Colors, typography and layout: `style.css`
- Gallery filters + lightbox: `script.js`
- Hero image: `.hero-image` in `style.css`
- About portrait: `.portrait-frame:before` in `style.css`

## Recommended image preparation
Export web images around 2000px on the long edge, JPEG/WebP, quality 75–85%. Keep individual files ideally below 1 MB.
